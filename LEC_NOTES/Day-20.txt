Redux has given an approach that instead of containing data into the component's local state, we should keep the data into the centralized store

Redux has 3 fundamental building blocks:
1. Action : The name of operation, and developer has to decide the name manually
		and once action has been created, now in order to update the store data, action has to be fired/dispatched

action is an object : {type:"INCREMENT_SCORE"}, {type:"DECREMENT_SCORE"}

 
2. Reducer : function that will be executed for the dispatched action, reducer function will automatically have the access for current action fired and the redux store
the data returned by the reducer function will become the latest store data
