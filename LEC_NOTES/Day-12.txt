there are two ways to send data in the request

1. url parameter
2. request body: along with the request we can send the data without showing it on the url

response data -> response body

request data -> request body

GET request method can't handle the request body

by default express app doesn't process the request body by itself

because we can have any type of data in the request body like json, binary, graphql so express can't decide by itself that what type of request body it has to process
 
a developer has to manually enable the processing of the request body

middleware: is a function that will be executed before request processing starts
so when request arrives on a server now 1st the middleware will be called and then the actual processing will be started


request arrives -> middleware -> callback fn processing request and response

express js also provides some predefined middlewares and developer also can create middlewares

import express from 'express';

const app = express();

app.use(express.json()); // if a middleware has to be executed for every request

app.get("/",(request,response)=>{
    response.send({message:'Welcome to app'})
});

app.post("/sum",(request,response)=>{
    console.log(request.body);
    response.send({message:"hello"});
});

app.post("/factorial",(request,response)=>{
    console.log(request.body);
    response.send({message:"hello"});
});

app.listen(4500);
