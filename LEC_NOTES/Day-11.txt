there are two types of 3rd party modules:

1. local module: installed specifically inside of a project
	
	p1 p2 p3 
	
if a module is providing predefined code base like functions, properties, classes then we must have to install it locally

when any module is installed locally then all its related folder and files will be stored inside node_modules

local module can be referred as dependency

when any dependency/local module is installed then its name with version will go inside the package.json file in the dependencies key 

and whenever we are moving the project folder or pushing the project on the git so we don't need to take node_modules folder due to its large content, simply take the project without node_modules folder and just hit 'npm i' command, and this command will look into package.json file and install all the mentioned dependencies


2. global module: not installed specifically inside of a project, installed in the system directly 

	npm i module-name -g 
	
        npm i nodemon -g

import express from 'express';

const app = express(); // create an express application and this will act as a server

app.get("/", (request, response) => {
    response.send("hello welcome to home");
});

app.get("/login", (request, response) => {
    response.send("this is login response");
});

// /sum/3/5
app.get("/sum/:a/:b", (request, response) => {
    // {a: 3, b:5}
    const n1 = parseInt(request.params.a);
    const n2 = parseInt(request.params.b);
    const n3 = n1 + n2;
    response.send({ sum: n3 })
});

app.get("/factorial/:num", (request, response) => {
    try {
        const value = parseInt(request.params.num);
        if (value <= 0) {
            response.status(400).send({ message: 'Invalid value given' })
        }
        else {
            var f = 1;
            for (var i = 1; i <= value; i++) {
                f = f * i;
            }
            response.status(200).send({ factorial: f });
        }
    } catch (error) {
        response.status(500).send({ message: 'Something went wrong' })
    }


});


app.listen(5500);
